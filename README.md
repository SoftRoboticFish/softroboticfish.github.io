# Soft Robotic Fish

Research website for a Carangiform-inspired cable-driven soft robotic fish and its rigid finite element (RFEM) model for lateral undulation and force prediction.

**Website:** https://softroboticfish.github.io/

## Publications

- R. H. Varnousfaderani *et al.*, “Lateral Undulation and Force Prediction in Soft Robotic Fish: A Systematic Approach,” *Journal of Bionic Engineering* (2025). [DOI](https://doi.org/10.1007/s42235-025-00786-6)
- M. Estarki *et al.*, “Design and Implementation of a Soft Robotic Fish Based on Carangiform Fish Swimming,” *ICRoM* (2021). [DOI](https://doi.org/10.1109/ICRoM54204.2021.9663484)

This repository hosts the project website only. For the complete research papers, including methodological details and experimental results, please refer to the official publisher pages linked above.
